Chrome Web Store 与 Edge Add-ons 均要求逐项声明数据用途。按以下内容填写：

### 4.1 单一用途说明 (Single Purpose)

```
CrabTab 的单一用途是替换浏览器的新标签页与主页，提供一个可自定义的起始页：
展示时钟、搜索框、快捷方式与最近访问，并附带壁纸、天气、书签栏和本地小工具。
```

### 4.2 权限用途说明 (Permission Justification)

| 权限 | 用途说明 |
| :--- | :--- |
| `storage` | 保存用户的界面设置、自定义快捷方式、待办事项、倒数日与搜索历史，使其在重新打开标签页后依然保留。所有数据仅存于本机。 |
| `bookmarks` | 读取浏览器书签，用于顶部常驻书签栏与书签搜索弹窗的展示。不会修改、删除或上传书签。 |
| `history` | 读取浏览历史，用于「最近访问」卡片流与历史记录抽屉的展示。可在设置中关闭该功能。 |
| `geolocation` | 获取粗略位置以显示本地实时天气。定位仅用于查询城市名与坐标，不存储、不上传。拒绝授权时天气组件会退回默认城市并正常显示，不影响其他功能。 |
| `favicon` | 获取站点图标，用于快捷方式与书签的图标展示。 |
| `host_permissions` | 仅访问壁纸图源、天气服务、搜索建议、一言与版本检查所需的接口域名。 |

### 4.3 数据使用声明（如实勾选）

| 声明项 | 勾选 |

| 是否收集健康信息 | 否 |

| 是否收集身份验证信息 | 否 |
| 是否收集个人通信内容 | 否 |
| 是否收集位置信息 | **是**（仅用于本地天气展示，不存储、不上传） |

## 五、隐私政策

Chrome Web Store 要求使用 `geolocation`、`history` 等敏感权限时必须提供可公开访问的隐私政策链接。

仓库当前**尚无隐私政策文件**。建议在仓库根目录新建 `PRIVACY.md` 后，将 GitHub 链接填入商店后台。可直接使用以下内容：

```markdown
# CrabTab 隐私政策

最后更新：2026-09-18

CrabTab（下称「本扩展」）尊重并保护用户隐私。本政策说明本扩展如何处理数据。

## 我们收集什么

本扩展不设账号系统，不收集、不存储、不上传任何可识别个人身份的信息。
本扩展不包含任何分析、埋点或广告 SDK。

## 数据存储在哪里

以下数据全部保存在你自己的浏览器本地（`chrome.storage.local` 与 IndexedDB），
不会同步到任何服务器，卸载扩展即一并删除：

- 界面设置：主题、语言、壁纸、界面缩放等偏好
- 自定义内容：快捷方式、待办事项、倒数日、搜索历史

- 获取搜索建议（你输入的关键词会发送至所选搜索引擎）

## 第三方

本扩展调用的第三方服务（天气、壁纸、搜索建议等）各自适用其隐私政策。
```

### 提交哪个包

```bash
npm run build          # 生成 dist/
npm run package:store  # 产出 CrabTab-v<版本>-store.zip（商店提交用）
```

| 包名 | 用途 | 是否含 `key` |
| :--- | :--- | :--- |
| `CrabTab-v<版本>-store.zip` | **提交到 Chrome Web Store / Edge Add-ons** | 否（已剥离） |
| `CrabTab-v<版本>-chrome-extension.zip` | 本地「加载已解压的扩展程序」、GitHub Release 分发 | 是 |

`key` 字段用于在本地加载时固定扩展 ID（ID 变化会让浏览器按新 ID 重新分配存储，用户数据看起来"丢失"）。但商店用自己的密钥签名并分配 ID，提交包中含 `key` 会被直接拒绝并报「清单不应包含 key 字段」。两个包不可混用。

## 八、待确认的技术问题

> 撰写文案时核对代码发现，以下两项可能影响上架或用户实际体验，建议发版前确认。

### 8.1 翻译服务已移除 LibreTranslate（原问题已解决）

原「翻译」提供四个服务商，其中 LibreTranslate 始终不可用：其域名未在 `manifest` 声明，且服务改为需申请密钥后已不接受匿名调用，实测必然失败。该选项已连同其请求实现一并移除，现仅保留三个可用服务：

| 服务 | 说明 |
| :--- | :--- |
| Google 翻译（免费） | 默认项，`translate.googleapis.com` |
| MyMemory（免费） | `api.mymemory.translated.net`，返回通配 CORS 头，已实测可用；需明确指定源语言，不支持「自动检测」 |
| 浏览器本地翻译 | 依赖 Chrome 内置 Translator API，需浏览器支持 |

**仍待确认**：`translate.googleapis.com` 与 `api.mymemory.translated.net` 目前都不在 `manifest.json` 的 `host_permissions` 中。二者靠目标服务自身的 CORS 响应头放行（MyMemory 已确认返回 `Access-Control-Allow-Origin: *`），但建议在真实扩展环境（非 `npm run dev`）中实测一次，确认后再保留文案中对翻译功能的宣传。

### 8.2 文本处理工具的具体能力

文案中「文本处理」写得较概括。核对实现后实际包含：大小写转换、去除空行、逐行去空格、重复行去重、字数/词数统计（中英混合分词）等。如需在商店页更具体地介绍，可据此展开。

### 8.3 README 中两处宣传与实现不符

撰写本文案时逐条核对代码，发现 README 里有两处描述**在实现中并不存在**，本文案已剔除，但建议一并修正 README，避免误导二次开发者：

1. **「随壁纸亮度自动适配」深色模式**：主题只有 `dark` / `light` 两个可选值，代码中的 `auto` 分支读的是**系统**深浅色偏好（`prefers-color-scheme`），且界面上没有暴露该选项。不存在根据壁纸图片亮度自适应切换的实现。
2. **「可在设置中手动指定天气城市」**：固定城市只能通过手动写入 `localStorage` 的 `crab_custom_weather_location` 键生效，设置界面中**没有对应入口**。对普通用户而言该能力不可达。

此外 README 的「核心特性」一节还停留在较早版本，未涵盖后来加入的顶部书签栏、实用工具抽屉（翻译 / 文本处理 / 测速 / 待办 / 倒数日）与全局界面缩放系统，建议同步更新。
